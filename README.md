# InvoiceFlow Frontend

A clean, minimalist, high-performance Next.js application built for the **InvoiceFlow** ASP.NET Core backend.

---

## 🎨 Design Philosophy
- **Utilitarian & Professional**: Strict adherence to clean typography, whitespace, and neutral slate tones.
- **No AI-slop or radiant gradients**: Designed specifically without rainbow gradients, floating pastel blobs, or visual clutter.
- **Accessible & Responsive**: Fully usable across desktop, tablet, and mobile displays.

---

## 🚀 Features Mapped to Backend Endpoints

### 1. Authentication & Profile (`/login`, `/register`, `/settings`)
- **Login (`POST /api/users/login`)**: JWT token authentication with secure client-side session handling.
- **Register (`POST /api/users`)**: Create an accountant profile with designated Bank (`HBL`, `ASKARI`, `ALFALAH`, `UBL`, `MCB`), IBAN / Bank Account Number, and Digital Wallet (`EasyPaisa` / `JazzCash`).
- **Profile & Payout Settings (`GET /api/users/me`, `PUT /api/users/{id}`)**: Update payout coordinates that are automatically printed on invoices and emails.

### 2. Invoices Management (`/invoices`, `/dashboard`)
- **Invoice Overview & Search**: Filter by status (`All`, `Pending`, `ProofSubmitted`, `Paid`, `Rejected`) and search by invoice #, client name, or service description.
- **Create Invoice (`POST /api/invoices`)**: Select client, amount, issue date, due date, recurring status. Triggers backend PDF generation, token generation, and email dispatch.
- **Invoice Actions**:
  - Download Invoice PDF (`GET /api/invoices/{id}/pdf`)
  - Mark as Paid (`PATCH /api/invoices/{id}/mark-paid`)
  - Delete Invoice (`DELETE /api/invoices/{id}`)
- **Payment Verification / Proof Review (`GET /api/payment-proofs/invoice/{id}`, `PATCH /api/payment-proofs/{id}/review`, `GET /api/payment-proofs/{id}/file`)**:
  - View receipts uploaded by clients.
  - Approve Proof (marks invoice as Paid).
  - Reject Proof (requires reason, sets status to Rejected).
  - Download receipt file directly.

### 3. Clients Directory (`/clients`)
- **Directory (`GET /api/clients`)**: Search by name, email, phone, company, or city.
- **Client Management (`POST /api/clients`, `PUT /api/clients/{id}`, `DELETE /api/clients/{id}`)**: Add, update, and remove clients.
- **Bulk Import (`POST /api/clients/import`)**: Drag-and-drop CSV or Excel (`.xlsx`) file with automatic duplicate email skipping and sample CSV download.

### 4. Accounting Reports (`/reports`)
- **Monthly Excel Export (`GET /api/invoices/report?year={year}&month={month}`)**: Download standardized `.xlsx` reports generated by ClosedXML.
- Live summary metrics for the selected month.

### 5. Public Customer Portal (`/pay/[token]`)
- **No-Auth Client Access (`GET /api/public/invoices/{token}`)**: Client reaches this portal directly from the payment link in their email.
- Displays amount, due date, and formatted bank / wallet payment instructions.
- Client downloads official invoice PDF (`GET /api/public/invoices/{token}/pdf`).
- Client uploads payment receipt (`POST /api/public/invoices/{token}/proof` with JPG, PNG, PDF <= 5MB).
- Immediately pauses reminders and notifies the accountant.

## 🛠 Running the Application

### Prerequisites
- .NET 10 SDK (Backend running on port 5012)
- Node.js v18+

### Development Server
```bash
cd InvoiceFlowFrontend
npm run dev -- --port 3000
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
The API calls to `/api/*` are automatically proxied to the backend at `http://localhost:5012/api/*`.
